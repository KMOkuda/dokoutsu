## 3. 処理の流れ

### 3.1 初期表示時 (GET)

1. ログイン中のユーザーのProblemのうち、deadline経過またはclosed_atが設定済みのものを、終了日時が新しい順に取得する
2. 各Problemの回答数を集計する
3. 該当するProblemが0件の場合、空の状態の案内を表示する

### 3.2 送信時 (POST)

**問題を削除する**

1. 対象ProblemのIDを受け取る
2. 対象Problemがログイン中のユーザーのものであることを確認する
3. Problemを削除する。ON DELETE CASCADEにより、紐づくAnswerPostも合わせて削除される
4. 一覧を再取得する

## 4. 画面構成

### 4.1 UI要素の動作

| 要素 | 種類 | 動作 | 活性・表示条件 |
|---|---|---|---|
| 戻るボタン(ヘッダー) | ボタン | 直前の画面に戻る | アプリ内の画面から遷移してきた場合のみ表示する(共有URLを直接開いた場合は表示しない) |
| 回答 Nボタン | ボタン | 回答一覧画面へ遷移する。Nは回答数 | 常時活性 |
| 「…」ボタン | ボタン | 削除ボトムシート(問題を削除する/キャンセル)を開く | 常時活性 |
| ボトムシート内「問題を削除する」 | ボタン | 削除確認ダイアログを開く | 常時活性 |
| 削除確認ダイアログ内「削除する」 | ボタン | Problemを削除する | 常時活性。送信中(押してから次の画面が表示されるまで)は非活性 |
| シェアボタン | ボタン | シェアシートを開く。項目はLINE・X・メール・リンク・他のアプリでシェア・キャンセル | 常時活性 |
| シェアシート内「LINE」「X」 | リンク | それぞれのサービスの投稿画面を開き、問題のタイトルと回答投稿画面のURLを共有する | 常時活性 |
| シェアシート内「メール」 | リンク | メールアプリを開く。件名に問題のタイトル、本文に回答投稿画面のURLを入れる | 常時活性 |
| シェアシート内「リンク」 | ボタン | 回答投稿画面のURLをコピーし、表示を「コピーしました」に変える | 常時活性 |
| シェアシート内「他のアプリでシェア」 | ボタン | OS標準の共有シートを開く | 常時活性 |

### 4.2 レイアウトの制約

| 項目 | 内容 |
|---|---|
| 表示順 | 終了日時が新しい順に上から並べる |
| 可変・固定 | カード一覧は縦スクロールで可変 |
| その他 | 空の場合はカード一覧の代わりに案内文を表示する |
