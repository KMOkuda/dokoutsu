# 要件定義書

## 1. プロジェクト概要

| 項目 | 内容 |
|---|---|
| プロジェクト名 | どこ打つくん |
| 目的 | 仲間内で囲碁の問題をシェアし、検討し合う |
| 開発手法 | アジャイル型 |
| 開発方式 | AI駆動開発 |
| 期間 | 2ヶ月(休日中心、実働40〜60時間) |

---

## 2. 背景・目的

大学囲碁部OBOG幹事として、囲碁の上達を支援したいという動機から出発した。
明確な課題認識があるわけではなく、探索的に進める前提とする。

仲間内で問題を出し合い、回答を見せ合って検討することで、
囲碁に触れる機会を増やすことを狙う。

---

## 3. 対象利用者

| 区分 | 内容 |
|---|---|
| 主な利用者 | 仲間内(大学囲碁部の現役部員・OBOGなど) |
| 想定人数 | 数人〜数十人 |
| 将来の想定人数 | 登録ユーザー総数で数百人規模への拡大を見込む |
| 利用場面 | 手が空いたときにスマートフォンから利用する |

---

## 4. 機能要件

### 4.1 問題を作る

| ID | 要件 |
|---|---|
| F-01 | 出題したい局面を自分で作成する |

### 4.2 問題を共有する

| ID | 要件 |
|---|---|
| F-02 | 作成した問題を仲間に閲覧させる |

### 4.3 問題に回答する

| ID | 要件 |
|---|---|
| F-03 | 問題に対する回答と、その意図を投稿する |
| F-04 | 同じ問題に対する他の人の回答投稿を閲覧する |

### 4.4 問題を管理する

| ID | 要件 |
|---|---|
| F-05 | 回答の受付を締切前に終了する |
| F-08 | 作成した問題を削除する |

### 4.5 自分の記録を見る

| ID | 要件 |
|---|---|
| F-06 | 自分が作成した問題のうち、受付中のものを参照する |
| F-07 | 自分が作成した問題のうち、受付を終了したものを参照する |

### 4.6 アカウントを使う

| ID | 要件 |
|---|---|
| F-09 | アカウントを作成する |
| F-10 | 認証する |
| F-11 | パスワードを忘れた場合に再設定する |

---

## 5. 認証

利用者の立場ごとに、操作に認証を要するかを定める。

### 5.1 出題者(問題を作る側)

| 操作 | 認証 | 対応要件 |
|---|---|---|
| 問題を作成する | 必要 | F-01 |
| 作成した問題を共有する | 必要 | F-02 |
| 回答の受付を終了する | 必要(本人のみ) | F-05 |
| 自分の問題の一覧を参照する | 必要 | F-06, F-07 |
| 問題を削除する | 必要(本人のみ) | F-08 |

### 5.2 回答者・閲覧者(問題を解く側)

| 操作 | 認証 | 対応要件 |
|---|---|---|
| 共有された問題を閲覧する | 不要 | F-02 |
| 回答とその意図を投稿する | 不要 | F-03 |
| 他の人の回答投稿を閲覧する | 不要 | F-04 |

---

## 6. 非機能要件

| 項目 | 内容 |
|---|---|
| 対応環境 | スマートフォンのブラウザを主とする。PCからも閲覧できることが望ましい |
| 同時利用 | 数人〜数十人。高負荷は想定しない |
| 応答性能 | 特段の要求はない(検証段階のため) |
| 可用性 | 特段の要求はない。停止しても業務影響はない |
| 個人情報 | 認証情報と投稿内容を保持する。機微情報は扱わない |
| 回答投稿 | 荒らしを防ぐため、同じ接続元から同じ問題への短時間の大量投稿を制限する |
| メール送信 | 迷惑送信を防ぐため、確認メールとパスワード再発行メールの送信回数を、送信先のメールアドレスごと・機能ごとに制限する |
| セキュリティ | 詳細は `.claude/skills/security-guideline/SKILL.md` に定める |

---

## 7. 制約条件

| 項目 | 内容 |
|---|---|
| 著作権 | 既存の詰碁を利用する場合、パブリックドメインのものに限る。解説文は自作する |
| 開発体制 | 1名。実働40〜60時間 |
| 既存資産 | 棋譜再生の実装経験がある(次期以降の機能で流用を検討) |

---

## 8. スコープ管理

### 8.1 第1イテレーションの範囲

| 優先順 | 内容 | 対応要件 |
|---|---|---|
| 1 | 認証、問題の作成 | F-01, F-09, F-10 |
| 2 | 問題の共有・閲覧 | F-02 |
| 3 | 回答投稿・閲覧 | F-03, F-04 |
| 4 | 回答の受付終了 | F-05 |
| 5 | 自分の記録の参照 | F-06, F-07 |
| 6 | 問題の削除 | F-08 |
| 7 | パスワードの再発行 | F-11 |

次期以降に持ち越す機能は `docs/not_doing.md` を参照。

---

## 9. 進行管理

### 9.1 判断地点

| 時期 | 確認内容 | 判断 |
|---|---|---|
| 約3週間後 | 複数アカウントによる自己検証で動作するか | 続行 / 範囲縮小 |
| 約6週間後 | 仲間に使ってもらい、継続の感触があるか | 続行 / 方向転換 / 終了 |

### 9.2 完了の定義

第1イテレーションの範囲が動作し、仲間に共有できる状態になっていること。
